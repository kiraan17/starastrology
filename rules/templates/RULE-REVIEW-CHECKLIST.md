# Rule Review Checklist

Copy into expert review records:

- [ ] `rule_id` / `technique_id` correct
- [ ] Sources are Approved (or explicit product_rule)
- [ ] Variant decision recorded if authors disagree
- [ ] Inputs, units, preconditions clear
- [ ] Conditions and exceptions unambiguous
- [ ] Activation separated from natal formation when required
- [ ] Output is structured evidence (not user prose)
- [ ] Safety level appropriate
- [ ] Positive / negative / boundary (and cancellation/activation) tests present
- [ ] No cross-school silent assumptions
- [ ] Version and change note present
